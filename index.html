Selection rule: stop at the first phase with a valid move. Within that phase, choose the lowest final score, then the named tie order. A later phase never outranks an earlier phase.
Score rule: base technique score + link modifiers + ALS_RCC digit modifiers. Strong-link modifiers are type 0=0.01, type 1=0.03, type 2=0.04, type 3=0.05, and type 4=0.06; ALS_RCC adds 0.01 per distinct digit in each ALS set.

Search Flow / Score Math

Final move score major technique score + link modifiers + ALS_RCC digit modifiers + shape/form modifiers Ordinary links Type 0 +0.01; Type 1 +0.03; Type 2 +0.04; Type 3 +0.05; Type 4 +0.06 ALS_RCC +0.01 per digit in each unique set; 2 digits = +0.02, 3 digits = +0.03, and so on ALS_RCC passes 2 digits → 3 → 4 → ... → configured maximum; larger passes are skipped when they cannot win Fish n + (0.25 * K) + Franken 0.125 or Mutant 0.25 Chain / ALS base + length excess + unique-digit excess + link curve + Open 0.25 or Ring 0.5 Transport named transport modifier +1.0; generic chain length already accounts for length DDS / ADDS ALS-DOF = 12 + (0.25 * (DOF - 1)); DDS ring adds 0.5; Almost DDS adds 0.25 beyond DDS DDS / ADDS Chain base 13; Ring adds 0.5

The solver follows the phases above. It selects the lowest final score only among valid moves in the current phase; ties use that phase's item order.
